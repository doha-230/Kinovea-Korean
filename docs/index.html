1. 빠른 시작

  1. 설치 파일 받기 — 릴리스에서 Kinovea-2026.1.0.exe(설치용) 또는 Kinovea-Portable-2026.1.0.zip(포터블) 중 하나를 받습니다.
  2. 영상 열기 — 파일 ▸ 열기. 한국어 경로·한국어 파일명도 정상 동작합니다.
  3. 프레임 스킵 확인 — 느린 PC이거나 긴 영상을 훑을 때 Ctrl+Shift+S 로 켜고 끕니다. (4장)
  4. 분석 후 내보내기 — 측정값을 CSV/Excel로, 필요하면 오디오 음량도 함께 뽑습니다. (7~8장)

4. 프레임 스킵 — 사용자가 켜고 끕니다

프레임 스킵은 디코딩 부담을 줄이거나 긴 영상을 빠르게 훑을 때 사용합니다. 이 포크에서는 사용자가 직접 켜고 끌 수 있고, 세 가지 동작 모드를 고를 수 있습니다.

4.1 켜고 끄기

환경설정선호사항들 ▸ 재생 탭 ▸ “시간이 부족하면 프레임 건너뛰기 허용”
단축키Ctrl+Shift+S
상태 확인재생바 표시: Skip off(꺼짐) / Skip 3(수동 3프레임)
끄면 전부 멈춥니다 — 마스터 스위치를 끄면 수동·자동·모션 적응 스킵이 모두 무효가 되고 다음 프레임부터 즉시 반영됩니다(재생 재시작 불필요).

4.2 세 가지 모드

모드동작쓰는 상황
자동 (기본)PC가 버벅이면 필요한 만큼만 건너뛰어 실시간 재생 유지대부분의 재생. 기존 동작 그대로
수동사용자가 정한 개수(0~10)를 항상 건너뜀긴 영상 훑기, 특정 배속 검토
모션 적응움직임에 따라 개수를 자동 가변 (5장)정지·반복 구간이 많은 영상

선호사항들 ▸ 재생 탭에서 모드와 건너뛸 프레임(0~10)을 지정합니다. 설정은 저장되어 다음 실행에도 유지됩니다.

4.3 수동 스킵 조작

1프레임 늘리기Ctrl+Shift+↑
1프레임 줄이기Ctrl+Shift+↓
증감 시수동 모드로 전환되고 스킵이 켜집니다
상한10프레임 (초과 입력은 자동으로 잘림)
권장 운용
  • 정밀 분석(관절 각도, 미세 동작): 스킵 끔. 프레임 단위 재생이 정확합니다.
  • 훑어보기(장면 찾기): 수동 3~5프레임.
  • 정지가 많은 영상: 모션 적응 — 대기 구간은 빠르게, 동작 구간은 촘촘하게.
  • 트래킹 중: 스킵은 자동으로 최소화됩니다 (6.4).

5. 모션 적응 스킵 — 정지면 많이, 움직이면 적게

장면의 움직임 양을 측정해 건너뛰는 프레임 수를 자동으로 정합니다.

그림 1. 모션 적응 스킵의 판단 흐름

5.1 켜는 방법

  1. 선호사항들 ▸ 재생 탭을 엽니다.
  2. “시간이 부족하면 프레임 건너뛰기 허용”이 켜져 있는지 확인합니다(마스터 스위치).
  3. 모드에서 모션 적응을 선택합니다.
튜닝 팁 — 움직임이 적은데 스킵이 잘 안 걸리면 건너뛸 프레임 값을 키우고(예: 10), 동작 구간이 너무 건너뛰면 수동 모드로 내려 정밀 구간만 프레임 단위로 보는 편이 안전합니다.
현재 한계
  • 움직임 기준값이 고정 상수라 영상마다 체감이 다릅니다(민감도 조절은 개선 후보).
  • 측정값이 없을 때(재생 시작 직후)와 트래킹 중에는 스킵하지 않습니다.

6. 트래킹

6.1 기본 순서

  1. 추적할 대상을 한 프레임에서 정확히 표시합니다.
  2. 추적 설정에서 검색창 / 대상 크기를 지정합니다.
  3. 추적 시작 → 궤적 확인. 어긋난 구간은 되돌려 다시 시작합니다.

6.2 주요 파라미터

파라미터의미조정 요령
검색창직전 위치 주변에서 찾는 범위빠른 동작이면 크게(150~200). 커지면 느려짐
대상 크기비교할 템플릿(마커) 크기대상과 비슷하거나 약간 크게
유사도 임계값이 값 미만이면 실패로 간주배경이 복잡하면 높게

6.3 이 포크의 개선 — 실패 시 확대 재탐색

대상을 순간적으로 놓치면 기존에는 이전 위치에 멈춘 채 실패로 끝났습니다. 이제 자동으로 검색창을 1.5배 → 2배로 넓혀 한 번 더 찾습니다(최대 400px).

정상 성공 경로전혀 바뀌지 않음
효과빠른 동작(스프린트·점프)에서 추적이 끊기는 빈도 감소

6.4 프레임 스킵과의 관계

  • 트래킹 중에는 자동 프레임 스킵이 꺼지고 모션 적응도 동작하지 않습니다 — 추적이 프레임 연속성을 전제로 하기 때문입니다.
  • 정밀 추적 시에는 스킵 마스터 스위치를 꺼 두는 것이 가장 안전합니다.

7. 측정값 내보내기

기본값은 BOM 없는 UTF-8 입니다. 한국어 Excel은 이를 CP949로 오인해 한글이 깨질 수 있습니다.

8. 오디오 음량 추출 포크 추가 기능

영상의 소리 크기를 시간축 데이터로 뽑아 표로 저장합니다. 점프 착지음·공 충돌음·발소리 같은 이벤트 시점을 수치로 확인해 궤적·관절 각도와 나란히 대조할 수 있습니다.

그림 2. 오디오 음량 추출 흐름

8.1 사용 방법

  1. 영상을 연 상태에서 파일 ▸ 내보내기 ▸ 오디오 음량… 을 선택합니다.
  2. 창 크기(ms) 를 정합니다. 작을수록 세밀(예: 20~50), 클수록 부드럽게(예: 200~1000).
  3. 형식을 고릅니다: CSV / Excel(xlsx) / 텍스트(txt) / JSON.
  4. 저장 위치를 지정하면 추출 후 자동으로 파일이 만들어집니다.
창 크기 설정은 기억되어 다음에 그대로 씁니다.

8.2 출력 열

열의미
Time (s)영상 시작을 0으로 한 시간(초). 창의 중심 시각
RMS (dBFS)창 구간의 평균적 크기(체감 음량). 분석에 주로 쓰는 값
Peak (dBFS)창 구간의 최대 순간값(튐·충격음 탐지에 유리)

8.3 값 읽는 법

0 dBFS최대(더 이상 클 수 없음)
-20 dBFS상당히 큰 소리
-40 dBFS작은 소리
-100 dBFS무음(표시 하한)
활용 예 — 착지 순간의 Peak 급등 지점을 찾아 그 시각의 프레임을 프레임 스킵 끔 상태로 열면, 소리 이벤트와 동작 국면(phase)을 정확히 맞춰 볼 수 있습니다.
이런 경우에는 어떻게 되나요?
  • 오디오 트랙이 없는 영상 — “이 파일에는 오디오 트랙이 없습니다.” 안내 후 종료됩니다(파일 생성 안 됨).
  • ffmpeg.exe 가 없을 때 — “Kinovea 옆에서 ffmpeg.exe를 찾을 수 없어…” 오류. 설치본/포터블에는 기본 포함되어 있습니다.
  • 긴 영상 — 추출 중에는 대기 커서가 표시됩니다. 매우 길면 시간이 걸릴 수 있습니다.
  • 무음 구간 — -100 으로 기록됩니다(0이 아닌 하한값).

11. 문제 해결 (FAQ)

영상이 열리지 않거나 첫 프레임이 검게 나옵니다
  • 코덱 문제일 수 있습니다. 재생 설정에서 하드웨어 디코딩을 꺼서 다시 시도해 보세요(선호사항들 ▸ 재생).
  • 파일 경로가 매우 길거나 특수문자를 포함하면 복사 후 다시 시도해 보세요. (한국어 경로는 지원됩니다.)
재생이 끊기고 화면이 건너뜁니다
  • 자동 스킵이 실시간을 맞추기 위해 프레임을 건너뛰는 정상 동작입니다. 상태 표시로 확인하세요.
  • 화질보다 정확한 프레임 확인이 필요하면 스킵을 끄고(Ctrl+Shift+S) 프레임 단위로 보세요.
  • 속도를 1× 이하로 낮추거나 하드웨어 디코딩을 켜면 부담이 줄어듭니다.
엑셀에서 한글이 깨집니다
내보내기 인코딩을 UTF-8 (BOM, Excel) 로 바꿔 다시 내보내세요(7.1). 이미 만든 파일은 Excel의 “데이터 ▸ 텍스트/CSV 가져오기”에서 인코딩을 UTF-8로 지정해 열 수 있습니다.
트래킹이 중간에 멈춥니다
  • 검색창을 키우세요(빠른 동작). 이 포크는 실패 시 자동으로 1.5×·2× 확대 재탐색까지 시도합니다.
  • 대상 크기를 마커보다 약간 크게, 유사도 임계값을 조금 높여 보세요.
  • 트래킹 중에는 프레임 스킵이 꺼지므로, 스킵을 끈 상태에서 다시 시도해 보세요.
오디오 음량 추출이 실패합니다
  • 앱 폴더에 ffmpeg.exe 가 있는지 확인하세요(포터블은 압축 해제가 완전해야 합니다).
  • 영상에 오디오 트랙이 있는지 확인하세요(무음 영상도 트랙은 있어야 값이 나옵니다).
  • 파일이 네트워크 드라이브에 있다면 로컬로 복사 후 시도해 보세요.

12. 알려진 한계

① 일부 한글 표기가 어색합니다 (기계번역 흔적)

번역 누락은 0건이지만, 오래된 번역 중에는 의미가 어긋난 항목이 남아 있습니다(전체 검사에서 190건 의심). 예:

  • Cancel → “취소하다” (버튼에는 “취소”가 맞음)
  • 내보내기 메뉴 → “퍼지는도표 내보내기”, “궤적 씨 에스 브이…”
  • “틀 비율 결과냅니다:”(=Resulting framerate), “그림그리는것구 성 설정”(=Configure drawing)

대응: 이 매뉴얼은 올바른 용어를 사용했고, 필요하면 파일/메뉴의 영어 표기와 대조해 쓰세요. 용어 정리(번역 품질 검수)는 개선 후보로 등록되어 있습니다.
